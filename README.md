
# PhysicsLab3

Практическая работа №3 по физике. Моделирование столкновений двумерных прямоугольных тел.

## Реализация
- Дискретная проверка столкновений
- CCD (Continuous Collision Detection)
- Multi-rate симуляция
- Две экспериментальные сцены

## Запуск
1. Открыть `PhysicsLab3.slnx` в Visual Studio.
2. Установить .NET 8 SDK и компонент разработки классических приложений .NET.
3. Запустить проект (Ctrl + F5).

## Управление
- 1 — дискретная проверка
- 2 — CCD
- 3 — Multi-rate
- Tab — смена сцены
- R — перезапуск
- P — пауза
- M — экспорт результатов в CSV

## Сцены
1. Быстрый снаряд и тонкая стенка — демонстрация туннелирования.
2. Система неподвижных, обычных и быстрых объектов — сравнение методов.
